## 当前阻碍和边界

## 服务器内存预算

- 服务器检测到约 1,998 MiB 总内存；95% 上限固定为 1,898 MiB。`deploy/check-host-memory.sh` 在达到该值时失败关闭。
- Docker 容器硬限额总和不得超过 1,600 MiB，为系统及非容器服务预留至少 298 MiB。当前测试 Compose 的各容器硬限额合计 1,392 MiB。
- 每次启动或重建服务前运行 `deploy/memory-preflight.sh`；它先检查 Compose 配额总和，再检查主机当前已用内存。新增 OCR/AI 服务必须纳入同一预算。

- `gh auth status` 显示未登录，尚无法确认账号或创建、推送个人仓库。
- 服务器 MySQL 8.4 仍触发 Flyway 支持版本警告；生产部署前需确认兼容性。
- 当前服务器仍是 SSH 隧道隔离测试栈，原项目上传/删除接口尚未鉴权，不应公开端口。
- OCR 服务未在服务器常驻运行；测试环境尚未验证 PaddleOCR 模型内存峰值，上传页面在未配置 OCR 上游时会提示服务不可用，仍可手动录入批次。经营 Agent 的真实模型调用还需配置新密钥并评测。并发压测、消息故障注入、完整库存对账和 GitHub 推送仍未完成。
