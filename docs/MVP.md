# 邻药云 MVP

## 本阶段可演示范围

用户可按经纬度查询附近药房、商品和已发布预约活动。门店工作台使用原项目登录 Token，并按服务端当前用户校验门店负责人。负责人可以管理商品档案、库存批次、活动和 FEFO 批次顺序；预约使用 Redis Lua、MySQL 请求/Outbox 与 Kafka 异步建单，并支持查询、取消和核销。库存变化在 MySQL 事务中记录批次余额和库存流水。

演示门店的合成账号为手机号 `19900000001`、门店 ID `900010`。服务器隔离测试配置中，验证码接口会返回临时验证码供演示；该开关默认关闭，只能用于限于 SSH 隧道访问的测试栈。首次使用须运行 `db/demo/005-pharmacy-mvp-demo.sql` 建立演示门店和负责人映射，该 SQL 以 `SET NAMES utf8mb4` 写入，避免昵称乱码。不要将测试入口直接开放公网。

访问 `/` 使用附近药房页面，访问 `/pharmacy-admin.html` 使用门店工作台。门店工作台包括库存列表、商品表单、手动批次录入、OCR 候选复核与入库、经营分析助手和 FEFO 查询。短信服务未接入；本地或生产默认不回传验证码。

## MVP 尚未包含

真实 PaddleOCR 推理与准确率、真实经营 Agent 模型调用与评测、采购单管理、千用户并发与消息故障测试、完整库存对账、正式短信接入和生产部署审查仍待完成。服务器端 OCR 上游目前未运行，所以实机上传暂不可用；运营者仍可手动录入。当前状态不代表已满足真实药房经营或药品销售合规要求。处方药不可参与线上预约。
