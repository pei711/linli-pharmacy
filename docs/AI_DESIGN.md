# AI 功能设计

## OCR 智能入库

`services/ocr` 提供可选 FastAPI OCR 服务，PaddleOCR 延迟加载；图片大小、像素和格式有上限，文件在临时目录处理后删除。提取器输出商品名、规格、批号、生产/有效期、数量和采购单价等候选值。可选 LLM JSON 抽取默认关闭，密钥只从环境变量读取；校验失败回退规则抽取。

Spring Boot 负责店主权限、OCR 服务代理、单据草稿和 SKU 精确/模糊候选。OCR 文本及候选需人工校对；确认时要求规格与所选门店商品档案一致，并将采购单价写入审核审计；再写批次、库存流水。拒绝也记录原因。图片本身不存入数据库。OCR 上游不可用时返回明确错误，不改变库存。

真实 PaddleOCR 权重和真实模型调用尚未部署。服务器已通过隔离 mock 验证上传至确认事务，不代表识别准确率。OCR 评测集、供应商模板和人工复核效率还未测量。

## 药房经营助手

LangChain4j 接入 OpenAI 兼容聊天模型；业务上下文工具读取当前门店的库存概况和出库流水。AI 配置从环境变量注入，关闭请求/响应正文日志。模型不可用或未配置时返回 `RULES_FALLBACK` 规则摘要，避免把备用结果伪装成模型结论。

当前服务器使用占位 API key，真实模型 API 未调用。助手是只读分析入口，不自动修改商品、库存、活动或订单；当前也没有完成模型质量、越权提示注入和成本评测。
